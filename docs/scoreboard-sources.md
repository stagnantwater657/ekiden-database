# 届次计分板：累计事实与派生值

本轮只增加展示投影及独立补充事实，不修改 `data/editions/`、Registry、原始2030条成绩、来源记录或身份决定。补充文件为 `data/presentation/all-japan-2024.json`，由稳定的 `resultId` 关联原始区间成绩；它不是新比赛成绩导入批次。

## 官方累计数据与奖项

来源：[日本学生陸上競技連合，第56回全日本官方成绩](https://www.iuau.jp/sp1/ev2024/56meki/56meki_result.pdf)，采用第1–2页页脚 **2024/11/5 19:45** 版本。复核日期：**2026-11-14**。继续关联既有来源 ID `iuau-aj2024-completion-results`。

- 第2页27支队伍各8个区间的上段累计时间及综合顺位：216项，逐项保留页码、队伍号码和区间定位。
- 第1页8项区间赏；第1页以及第2页明确标识的2项区间新：第4区黒田朝日、第6区山本歩夢。两者可以同时显示；没有从本站有限届次中的最小值推算纪录。
- 每队累计时间逐区间与已核验的原始区间用时之和相符，终点值与既有官方总时间相符。最终25个正式排名相符；两支选拔队的累计排名始终为 `null`。
- 上段累计排名与下段区间个人顺位不同，不能互相代替。例如駒澤大第1区累计第13，个人区间第14。第2区青山学院大与創価大累计同为59:25，官方累计顺位分别为第1、第2，照录而不重排。
- 排名变化由上一棒官方累计顺位减去当前官方累计顺位得到；领先差由当前累计时间减去该区间官方累计第1的时间得到。这两个展示值为计算结果，并非额外的官方原始字段。
- 参考队保留可核验的官方累计时间，但不显示综合排名、排名变化或领先差。

本轮仅逐项核验第56回的区间赏与区间新。其他届次暂不加标签；缺少标签不代表没有获奖或创造纪录。赛事路线档案中的“官方区间纪录”属于特定路线版本的正式纪录资料，不能直接使用本届区间新标签或历史样本最低值填充。

## 独立派生规则

`lib/scoreboard.ts` 在读取 Repository 的 catalog 后建立只读视图。仅对全日本和出云的正常完整比赛允许计算：所有具有正式排名资格的队伍都必须正常完赛、已有正式最终排名、每区间均有正常且完整的用时，并且区间总和等于官方最终用时。全届任一正式队伍不满足这些条件，则不计算整届累计，避免将弃权队排除后误称当前领先队。

可计算的届次显示 **“按区间用时计算”**：

- 用时为前N个区间用时之和。
- 计算顺位只包括正式队伍；相同秒数采用并列顺位，下一顺位保留人数间隔。
- 明确不是官方通過順位。派生值没有虚构的官方累计来源；其输入保留原成绩来源并在页面来源区列出。
- 参考队不参与派生排名。第一区没有上一棒，排名变化为空。
- 排名变化、领先差均从同一种累计口径取得，不混合官方与计算字段。

当前模式：

| 届次 | 累计展示 |
| --- | --- |
| 全日本第56回（2024） | 官方216项累计事实 |
| 全日本第57、58回（2025、2026） | 完整区间用时派生，明确标注 |
| 出云第36–38回（2024–2026） | 完整区间用时派生，明确标注 |
| 全日本第55回（2023）、出云第35回（2023） | 含弃权／失格状态，累计待核验 |
| 箱根第100–102回（2024–2026） | 不套用普通累计规则，累计待核验 |

箱根的往路、复路、繰り上げスタート以及传递／实际通过时间口径需另行核验官方逐区间资料，本轮不凭简单相加生成其累计官方顺位。既有往返路和最终成绩保留。

最终综合视图只将正式完赛且具有官方最终排名的队伍列入排名表，冠军差距由官方总时间相减。参考、弃权、失格、未排名队伍单独呈现，不补造正式排名或差距。

## 验证与后续补录

`tests/scoreboard.test.ts` 核验216项关联和加和、独立官方实例、等秒不同官方顺位、计算并列顺位、变化、时间差、参考队、缺失数据、异常状态、全部11届区间排序和原数据库不变。官方奖项按姓名、用时和明确纪录标识核验。合成测试数据仅在测试内使用，不写入正式数据。

后续可按相同补充结构逐届收录具有来源定位的官方累计成绩及奖项；应核对采用版本、比赛规则和参赛资格，再扩大展示覆盖。不能以派生值覆盖官方字段，也不能据此推断PB或路线历史纪录。
