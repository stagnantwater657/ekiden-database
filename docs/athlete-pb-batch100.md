## 四、发现的问题（如实记录）

1. **过期报名值**：折田壮太 5000m 报名 PDF 公認 13:28.78 快于大学榜 13:33.32（2025-06-01）→ 报名值无日期，按规则不发布、不采用旧值，保留 candidate（同类：飯田翔大 5000m）。
2. **身份/生日冲突**：平林樹 sat-ekiden 生日 2002-12-08 与另一源 2002-12-06 冲突，且与浦田優斗的 sat 生日（2002/12/06）疑似串号 → 两人生日保持 candidate，不发布。
3. **毕业去向未确认**：平林樹疑入トヨタ紡織（连接 reset 无法核验）；谷村恒晟/秋山翔太朗 2026-03 毕业，最新可核实值停在 2025-10 出雲37；帰山侑大等 102 回 4 年生已毕业、实业团去向未查 → 相关 PB 一律 candidate，未用大学旧值冒充当前 PB。
4. **生年与学年矛盾**：浦田陽聖 ekiden-db 生年 2002 与其 2024 年 1 年次不符（疑似 2 浪），月日未知 → candidate。
5. **无法确认的成绩**：group2/3/5 的名鑑与报名值只有树立年或完全无日期（合计 272 字段 candidate）；新博貴 5 字段全部 not-found。
6. 官方 100/101 回区間エントリー PDF 均 404（仅 102 回可下载）；longjog 全站 429；KGRR 旧 PDF 404 —— 已记录于对应日志。

## 七、后续建议（100 → 1000 人的真实瓶颈）

1. **官方报名 PDF 的届次覆盖**：100/101 回 PDF 已从官网撤下（404）。archive.org 有索引但被 429 限流。建议先做一次性归档（Wayback 慢速重试或官方渠道索取），否则旧届次生日批量来源直接消失。
2. **PB 日期是最大瓶颈**：名鑑/报名表只有值、无日期。带日期的批量源目前只有各大学 10傑/记录页（每校一次抓取，可复用）与長野陸協 DATA_WEB 类田联库。建议为 26 校建立「记录页 URL 索引 + 解析器」，这是把 candidate 转 verified 的最高性价比动作。
3. **毕业生实业团归属**：约 1/4 选手已毕业。实业团档案一次批量抓取可解决「当前所属」和「毕业后新 PB」两类缺口；需要单独的实业团名鉴批量源。
4. **解析层**：箱根报名 PDF 的日文解析已可用（本批 324/336 行自动解析成功），出雲官网选手页是纯 HTML 好解析；建议把两类解析器收进 scripts/ 固化，后续批次直接复用。
5. **研究日志生成**：本批 500 条记录的 v2 日志由生成器产出并通过结构校验，但步骤声明需要逐批人工语义复核——1000 人规模时建议保留生成器 + 抽样人工复核，不做逐条手写。
