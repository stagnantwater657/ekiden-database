# UI 细节优化：第一轮

基于 PR #16 合并后的 `main`（`6bbad3c`）。本轮仅改展示和交互，不修改原始 11 届、2030 条成绩、身份关联、官方奖项及现行纪录资料，也不修改部署配置。

## 届次成绩表

- 点击区间顺位、累计用时、顺位变化表头切换升降序；默认区间顺位升序。
- URL 使用 `section`、`sort=rank|cumulative|movement`、`direction=asc|desc`。选择另一排序列时从升序开始；无效排序恢复默认。
- 切区间、最终综合后返回区间均保留排序及其他已有查询参数，刷新、分享和前进后退恢复同一状态。最终综合继续使用原有官方最终排名规则，不受区间排序影响。
- 顺位变化按带正负号的数值比较；缺失值在两个方向均置底，相同值按稳定 resultId 排序。更改区间/排序时清除无效旧页码。
- 箭头、`aria-sort` 和可用键盘访问的链接一起表达操作；上升深绿、下降深红且加粗，无变化中性灰。
- 区间概览只展示现有 `HonorFact` 明确认定的区间赏，不根据第一名推断，保留共同获奖者。原表中非获奖选手的区間新及区間タイ不变。

## 赛前纪录数据缺口

`data/presentation/races.json` 记录的是截至最新届次赛后的现行路线纪录；`courseEditionId`、`courseVersion` 和 `revision` 并不构成每届开赛前的纪录快照。现有按届次展示资料只包含官方累计数据与奖项事实，不能从中安全恢复完整的历史赛前纪录及所有共同保持者。

因此本轮 11 届的区间概览均明确显示“赛前纪录尚待核验”。不将 2026 现行纪录套用到旧届次，也不以本届区间新或本站有限成绩反推赛前纪录。后续须逐届核验比赛前有效的路线版本、纪录用时、全部保持者及大学、有效日期和来源定位，再接入概览。本轮没有声称已补齐这一数据缺口。

## 其他展示

- 首页沿用页面容器，标题与统计卡片采用相同内边距；调整两栏比例和间距。数字位于文字说明上方，四项一致。
- 赛事现行纪录表新增大学列。共同保持者各占一行，共享区间、距离、纪录用时单元格，确保姓名、大学和年份一一对应，保留链接与来源。
- 大学历届表现表列名简化为“综合顺位”“总成绩”；届次表的“累计综合顺位”简化为“综合顺位”。

## 验证范围

Node 测试覆盖默认排序、三列双向排序、正负变化、缺失值、稳定次序、数据不变及 URL 编解码。Playwright 覆盖表头点击与键盘、刷新/前进后退、区间及最终综合切换、共同获奖者、共同纪录保持者、非获奖新纪录、赛前纪录缺口，以及 1280/740/390px 首页布局与详情导航。沿用完整数据校验、类型检查、Lint、生产构建和现有 CI。

本轮执行结果：`data:validate`、`typecheck`、`lint`、94 项 Node 测试、生产构建及 22 项 Playwright 均通过。浏览器检查同时发现并修复了隐藏读屏文字越出表格滚动区的问题：滚动容器建立定位边界，手机端仍能横向滚动表格，但不会撑宽整页。
