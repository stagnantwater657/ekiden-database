## 核验结果与边界

- 2025：25所大学 + 日本学連選抜、東海学連選抜，216名实际出场选手，216条成绩。逐条核对第2页与第3–10页的姓名、队伍、区间用时、区间顺位；25个综合排名逐校核对第1页，27队各区间合计与官方总用时一致。
- 选拔队有官方区间顺位，但没有正式综合排名；保留原区间顺位，不重新计算，`finalRank=null`、`status=reference`。秒数相同可能顺位不同，也可能同顺位，完全保留官方事实。
- 60位跨年身份经过两年最终名单的完整姓名、同一大学、年级连续性（1→2、2→3、3→4）及旧成绩身份逐项核对，复用原ID。名单中研究生阶段及选拔队代表关系不按姓名自动合并。
- 5项审核：坂本亘生（本科→研究生身份）、鶴田寛武、赤澤京弥（大学→选拔队身份）；椙山一颯与名单中的榅山一颯、吉田黎大与名单中的𠮷田黎大（字形核验）。后两条保留成绩表姓名，年级留空。详情见 `data/reports/validation.json`。
- 选拔队成员的原属大学未从这些名单确证，`representingUniversityId=null`；展示选拔队，不虚构普通大学。已知年级保留 `M1`、`M2`，不误写成大五、大六。出生日期、PB未知，不填。
- 2024仍只覆盖25所大学200条成绩，仍未纳入两支公开选拔队；其原来源及覆盖说明保留。旧届总用时未在本批重新采集，保持空值。
