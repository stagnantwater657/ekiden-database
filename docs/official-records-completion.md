## 后续补齐方法

在 `data/presentation/editions/` 增加或修订一届补充文件，在统一index注册；不用修改原始届次。先人工核对具体官方表格和版本，再绑定已有resultId/entryId，并记录源定位。箱根中継所数据须取 NTV「記録速報」`SOGOU` 数组（総合順位/総合タイム），不得改用 `TSUKA` 走行順，也不得由区间用时排序生成名次；每点继承 `KURIAGE_FLG` 说明。区間賞必须有奖项证据；区間新/タイ须有官方标记，不能用本站成绩排序推断。每次执行 `npm run data:validate`、`npm run presentation:report`，检查报告差异和全部测试。箱根中继站须明确采用“有效累计比赛用时/综合顺位”，不可从现场走行顺序或区间时间合计生成正式事实。
