# UI 细节优化：第一轮

基于 PR #16 合并后的 `main`（`6bbad3c`）。本轮仅改展示和交互，不修改原始 11 届、2030 条成绩、身份关联、官方奖项及现行纪录资料，也不修改部署配置。

## 届次成绩表

- 点击区间顺位、累计用时、顺位变化表头切换升降序；默认区间顺位升序。
- URL 使用 `section`、`sort=rank|cumulative|movement`、`direction=asc|desc`。选择另一排序列时从升序开始；无效排序恢复默认。
- 切区间、最终综合后返回区间均保留排序及其他已有查询参数，刷新、分享和前进后退恢复同一状态。最终综合继续使用原有官方最终排名规则，不受区间排序影响。
- 顺位变化按带正负号的数值比较；缺失值在两个方向均置底，相同值按稳定 resultId 排序。更改区间/排序时清除无效旧页码。
- 箭头、`aria-sort` 和可用键盘访问的链接一起表达操作；上升深绿、下降深红且加粗，无变化中性灰。
- 区间概览只展示现有 `HonorFact` 明确认定的区间赏，不根据第一名推断，保留共同获奖者。原表中非获奖选手的区間新及区間タイ不变。

## 每届赛前区间纪录

- 新增 `data/presentation/prior-records.json`：每条记录按 `editionId + sectionNumber` 唯一，保存该届开赛前在有效路线下生效的纪录用时、全部保持者（姓名、所属大学、创造年份与届次）、路线版本、`sourceId`、locator 与 revision。
- 与 `races.json` 的现行纪录（截至最新届次赛后）分表保存、互不覆盖。届次页只读赛前快照；本届刷新纪录仍只以成绩表「区間新」标识呈现，不用新纪录覆盖概览，也不据区间赏反推动纪录。
- 来源：箱根取关东学连各届《往復総合公式記録》p.1「過去区間最高記録」行（第100–102回）；全日本取 IUAU 各届成績表 p.2 大会記録（第55–58回）；出云取 IUAU 各届結果的区間記録行（第36–38回）；第35回 PDF 未印区間記録表，采用第36回官方表并在第35回无区間新、纪录未变的前提下引用（同位 locator 已注明）。
- 路线：11 届范围内三赛事路线未变（箱根 4/5 区自第93回调整，第100–102回同路线），每行校验当届区间距离与 `courseVersion` 所对应路线一致，不使用最新纪录倒填。
- 出云 1 区：第35–38回统一的赛前纪录采用第38回官方表的 22:30【第21回】（キラグ・ジュグナ／第一工業大学），来源定位指向该表。

## 其他展示

- 首页沿用页面容器，标题与统计卡片采用相同内边距；调整两栏比例和间距。数字位于文字说明上方，四项一致。
- 赛事现行纪录表新增大学列。共同保持者各占一行，共享区间、距离、纪录用时单元格，确保姓名、大学和年份一一对应，保留链接与来源。
- 大学历届表现表列名简化为“综合顺位”“总成绩”；届次表的“累计综合顺位”简化为“综合顺位”。

## 验证范围

Node 测试覆盖默认排序、三列双向排序、正负变化、缺失值、稳定次序、URL 编解码，以及赛前纪录的逐届逐区间状态、保持者不晚于届次、路线一致、共同保持者、来源与冲突拒绝。Playwright 覆盖表头点击与键盘、刷新/前进后退、区间及最终综合切换、共同获奖者、赛前纪录与本届区間新并存、共同纪录保持者、非获奖新纪录，以及 1280/740/390px 首页布局与详情导航。沿用完整数据校验、类型检查、Lint、生产构建和现有 CI。

本轮执行结果：`data:validate`、`typecheck`、`lint`、101 项 Node 测试、生产构建及 23 项 Playwright 均通过。浏览器检查同时发现并修复了隐藏读屏文字越出表格滚动区的问题：滚动容器建立定位边界，手机端仍能横向滚动表格，但不会撑宽整页。
